# Higgs Audio v3: Руководство по эффективному клонированию голоса (Voice Cloning Guide)

Данное руководство описывает принципы работы, рекомендации по записи эталонного аудио, готовые тексты для записи и способы сохранения профилей голоса в **Higgs Audio v3**.

---

## 1. Как работает клонирование в Higgs Audio v3

Higgs Audio v3 использует механизм **Zero-Shot In-Context Learning** (обучение в контексте без изменения постоянных весов модели):
1. Аудиофайл эталона (`samples/reference.wav`) пропускается через нейросетевой кодек (`HiggsAudioTokenizer`).
2. Звук преобразуется в последовательность дискретных кодов (**Voice Tokens**) с частотой 25 токенов в секунду.
3. Токены голоса подставляются в начало контекста модели перед синтезируемым текстом:
   `<|tts|><|ref_text|>[ТРАНСКРИПЦИЯ]<|ref_audio|>[КОДЫ ГОЛОСА]<|text|>[ТЕКСТ ДЛЯ ОЗВУЧКИ]<|audio|>`
4. Модель генерирует речь, подражая тембру, акустике и манере произношения из промпта.

## 2. Готовые тексты для записи эталона голоса

Для получения чистого и выразительного голосового профиля запишите один из следующих фрагментов длительностью **7–12 секунд** (~20–30 слов):

### Вариант 1. Фонетически сбалансированный дикторский текст (Рекомендуемый)
*Охватывает все гласные, шипящие, сонорные и парные согласные звуки русского языка, а также ровную повествовательную интонацию:*

> **«В тихой заводи реки плещется чистая вода. Солнечные лучи освещают зелёный лес, а лёгкий прохладный ветерок приносит ощущение глубокого спокойствия и радости.»**
* Длительность: ~8–10 секунд.
* Назначение: универсальный эталон для аудиокниг, подкастов и дикторского чтения.

### Вариант 2. Текст с естественной эмоциональной динамикой
*Позволяет модели уловить динамику живой речи, паузы и интонационную гибкость:*

> **«Сегодня мы начинаем новый важный проект. Будем двигаться спокойно, шаг за шагом, обращая внимание на каждую деталь. Результат обязательно превзойдёт все ожидания.»**
* Длительность: ~8–10 секунд.
* Назначение: живые диалоги, презентации и выразительное повествование.

### Вариант 3. Тематический текст с философской и санскритской лексикой
*Для точного воспроизведения специфической вайшнавской терминологии без акцента и искажений:*

> **«Шримад-Бхагаватам раскрывает науку преданного служения. Изучая стихи Бхагавад-гиты с терпением и вниманием, мы обретаем внутреннюю силу и духовное умиротворение.»**
* Длительность: ~9–11 секунд.
* Назначение: озвучивание лекций, философских текстов и цитат.

## 3. Пять правил качественной записи эталона

1. **Оптимальная длительность (7–12 секунд)**:
   - 7–10 секунд дают ~175–250 аудио-токенов в промпте (инференс на Apple M1 занимает **1–3 минуты**).
   - 60 секунд дают ~1500 аудио-токенов, что кратно увеличивает время внимания на каждом шаге.
2. **Точное соответствие текста (`ref_text`) 1-в-1**:
   - Текст в `samples/reference.txt` должен дословно совпадать со сказанным в `samples/reference.wav` (включая знаки препинания и регистр).
3. **Чистый сигнал без посторонних шумов**:
   - Записывайте в тихой комнате без эха (реверберации), вентиляторов, шума улицы и фоновой музыки.
4. **Естественный темп и дыхание**:
   - Говорите уверенно, с естественными паузами на запятых и точках, избегая задувания в микрофон (используйте поп-фильтр).
5. **Формат аудио**:
   - Моно, 16 кГц или 24 кГц WAV (16-bit PCM).

## 4. Как сохранить и переиспользовать профиль голоса (Voice Profile)

Чтобы не кодировать WAV-файл заново при каждой генерации, можно один раз сохранить дискретные коды голоса на диск (`.npy`):

### Экспорт голосового профиля:
```python
import numpy as np
from mlx_audio.tts.utils import load

model = load("bosonai/higgs-tts-3-4b", model_type="higgs_audio_v3")
voice_codes = model.encode_reference_audio("samples/reference.wav")
np.save("voices/my_voice.npy", np.array(voice_codes))
print("Профиль голоса сохранён в voices/my_voice.npy")
```

### Генерация с сохранённым профилем:
```python
import numpy as np
import mlx.core as mx
from mlx_audio.tts.utils import load
from mlx_audio.audio_io import write as audio_write

model = load("bosonai/higgs-tts-3-4b", model_type="higgs_audio_v3")
saved_codes = mx.array(np.load("voices/my_voice.npy"))

results = list(model.generate(
    text="Харе Кришна! Это быстрая генерация с сохранённым профилем голоса.",
    ref_audio_codes=saved_codes,
    ref_text="В тихой заводи реки плещется чистая вода...",
    temperature=1.0,
    max_new_tokens=2048,
))

audio = np.concatenate([np.asarray(r.audio).reshape(-1) for r in results])
audio_write("output/speech_output.wav", audio, results[0].sample_rate)
```
